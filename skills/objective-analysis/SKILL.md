# Objective analysis

## Overview

Compare objective findings with clinical hypotheses through structural and system evidence tables. Identify support, opposition and uncertainty before handing off to the separate Impression stage.

## When to Use

Use for objective assessment analysis, updating subjective hypotheses, or the objective portion of an explicitly requested complete assessment. Accept original assessment data or an equivalent subjective handoff.

## Workflow

### Phase 0: Scope Check and Data Collection

1. **Required references:** Read [clinical contract](../../references/clinical-contract.md) and [stage routing](../../references/stage-routing.md).
2. Accept original assessment data or an existing subjective handoff; do not require a prior skill when equivalent context is already supplied.

3. **Evidence types:** Separate measurements, observations, patient reports and prior interpretations.
   - Preserve units, side, time and test conditions.
   - List unavailable subjective context and contradictions instead of inventing them.

4. **Missing findings:** Identify missing objective findings and request the information needed for the current analysis; do not invent findings to complete a table.
5. **Stage and mode:** Determine the current stage and whether a complete combined analysis was explicitly requested.

### Phase 1: Structural Evidence Analysis

1. **Structural template:** Read [Table 3.1](assets/table-3-1.md).
   - Preserve all five columns and the 13 original rows in order: Bone, Cartilage, Capsule, Ligament, Tendon, Muscle, Fascia, Nerve, Vessel, Bursa, Fat, Skin, Viscus.
   - Append case-relevant additional classes when needed, without deleting/reordering base rows or forcing Joint/Disc into an unreliable mapping.
2. **Supporting and opposing evidence:** Record supporting and opposing findings with source locators; use Not provided for missing findings.
3. **Support status:** Fill the support column with one approved status and its case rationale.
   - Unexamined categories may remain unknown; do not populate all rows with plausible diagnoses.
   - Major unresolved supporting/opposing conflict uses ⚠ Conflicting evidence.

### Phase 2: System and Regional Evidence Analysis

1. **System template:** Read [Table 3.2](assets/table-3-2.md).
2. **Column structure:** Use FIVE distinct columns, including separate Upstream and Downstream and Regions.
3. **System coverage:** Keep the six base system rows; append relevant other categories when needed.
4. **Title and status:** Use the exact corrected Regions title and an approved involvement status with reason.

- **Kinetic-chain reasoning:** When movement-related hypotheses are relevant, read the shared [kinetic-chain guide](../../references/kinetic-chain-analysis.md). Use supplied observations and examination findings to evaluate restrictions, control patterns and symptom relationships, and return the findings to Tables 3.1/3.2 as appropriate.

### Phase 3: Hypothesis Update and Handoff

1. **Contradictions and limitations:** After the tables, include Clinical Contradiction Alerts / Insufficient Evidence, then the clinical-contract Red Flags, Yellow Flags and Reasoning Rationale and Limitations.
   - Refer to table evidence without recopying it.
2. **Hypothesis update:** State which preliminary hypotheses were supported, weakened or remain undecidable and what would distinguish them.
3. **Objective stop:** Stop before Table 4/full Impression and invite a clear forward request.
   - If a complete combined analysis was explicitly requested, proceed using the available Impression skill as described in stage routing.
   - Without that capability, state the limitation rather than improvising completion.

## Interpretation Checks

Do not mistake missing sensory/neurodynamic findings for negatives. Possible neural involvement and suspected neural mechanosensitivity are not automatically neuropathic pain. Breathing response, posture, a fascial pathway or isolated provocative finding does not establish a specific causal lesion. Check method/source and population applicability when recommending a test; uncertain methods remain uncertain. Source examples' ratings are not defaults.

When interpreting pain descriptors, consult the shared [pain-mechanism guide](../../references/pain-mechanisms.md).

- [ ] Table 3.2 retains five distinct columns, separate Upstream and Downstream and Regions, the corrected Regions title and six base system rows.
- [ ] Supporting/opposing findings have source locators and preserve units, side, time and test conditions; missing findings remain unknown rather than negative.
- [ ] Each status uses an approved label with a case-specific rationale; major unresolved conflicts remain explicit.
- [ ] Clinical Contradiction Alerts / Insufficient Evidence and all three clinical-contract sections follow the tables.
- [ ] The update distinguishes supported, weakened and undecidable hypotheses, identifies what would distinguish them and respects the staged stop or explicit complete-analysis route.
