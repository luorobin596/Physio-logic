# Impression

## Overview

Synthesize subjective and objective evidence into Table 4 and a full clinical Impression. Keep the working explanation, confidence and limitations consistent across both outputs.

## When to Use

Use for final assessment synthesis or an explicit Impression request, including a clearly limited provisional synthesis when data are incomplete. End at assessment synthesis and relevant additional-assessment questions.

## Workflow

### Phase 0: Scope Check and Data Review

1. **Required references:** Read [clinical contract](../../references/clinical-contract.md), [stage routing](../../references/stage-routing.md) and [template selection](references/template-selection.md).
2. Accept traceable original assessment data or a stage handoff.
   - Do not assume tests occurred because a prior narrative mentions a diagnostic label.

3. **Case review:** Check case scope, data version, facts, prior hypotheses, support/opposition and unresolved issues.
   - If only subjective data exist, explicitly limit the synthesis; never present it as objectively verified.
   - Prioritize potentially urgent concerns over routine table completion.

   - If no assessment data or usable handoff exist, request them before generating a case Impression.
   - Use available context without requiring earlier stages to be rerun.

### Phase 1: Updated Hypothesis Table

1. **Updated-hypothesis template:** Read [Table 4](assets/table-4.md).
   - Preserve Item/Content and every row.
2. **Synthesis categories:** Distinguish a primary working explanation from secondary/contributing regions, functional limitations, pain descriptors and OPEN contributing factors.
   - Uncertain entries remain unknown.
3. **Concise table summary:** Keep the Impression cell concise.

### Phase 2: Full Clinical Impression

1. **Narrative templates:** Read [Impression templates](assets/impression-templates.md).
2. **Default version:** Default to Core template (full) after Table 4.
   - Its conclusion, confidence and limits must match the table.
   - Do not force a movement deficit, anatomical source, causal chain or test quota unsupported by the case.
3. **Required judgments:** Retain Stage, Irritability, Key evidence, Prognosis and Red flags.
   - Give each judgment a basis.
   - For Prognosis/Red flags with inadequate information use Insufficient information to determine at present; never fill good/fair or none from example text.
4. **Required sections:** Add Red Flags, Yellow Flags and Reasoning Rationale and Limitations as specified by the clinical contract.
   - Do not repeat table findings verbatim; emphasize material limits, competing explanations and verification questions.

### Phase 3: Version Offer and Close

- **Version offer:** After the full version, ask whether a Lean clinic-note version is wanted.
- Alternatively, when case context makes another template useful, name it, briefly explain why, and ask if wanted.
- Do not silently switch or output every variant.
- **Requested version:** If the user already requested a specific version, provide it directly without a redundant offer for that version.

- End at Impression and relevant additional-assessment questions.
- No exercise dosage, treatment plan, medication or automatic medical-record writeback.

## Interpretation Checks

When interpreting pain descriptors, consult the shared [pain-mechanism guide](../../references/pain-mechanisms.md).

## Verification

Before delivering the Impression, confirm:

- [ ] Table 4 retains Item/Content and every fixed row, with a concise Impression cell.
- [ ] The selected narrative version follows template-selection guidance and any explicit version request.
- [ ] The table and narrative agree on the working explanation, contributing factors, confidence and limitations.
- [ ] Stage, Irritability, Key evidence, Prognosis and Red flags have a case-supported basis; insufficient information is stated explicitly.
- [ ] Red Flags, Yellow Flags and Reasoning Rationale and Limitations are included without recopying table evidence.
- [ ] Subjective-only synthesis is clearly limited; no unsupported movement deficit, anatomical source, causal chain or test quota is imposed.
- [ ] The response ends at Impression and assessment questions, with the appropriate version offer and no unrequested treatment prescription or record writeback.
