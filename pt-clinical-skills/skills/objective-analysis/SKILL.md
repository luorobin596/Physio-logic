# Objective analysis

## Overview

Compare objective findings with clinical hypotheses through structural and system evidence tables. Identify support, opposition and uncertainty before handing off to the separate Impression stage.

## When to Use

Use for objective assessment analysis, updating subjective hypotheses, or the objective portion of an explicitly requested complete assessment. Accept original assessment data or an equivalent subjective handoff.

## Workflow

### Phase 0: Scope Check and Data Collection

Read [clinical contract](../../references/clinical-contract.md) and [stage routing](../../references/stage-routing.md). Accept original assessment data or an existing subjective handoff; do not require a prior skill when equivalent context is already supplied.

Separate measurements, observations, patient reports and prior interpretations. Preserve units, side, time and test conditions. List unavailable subjective context and contradictions instead of inventing them.

Identify missing objective findings and request the information needed for the current analysis; do not invent findings to complete a table. Determine the current stage and whether a complete combined analysis was explicitly requested.

### Phase 1: Structural Evidence Analysis

1. Read [Table 3.1](assets/table-3-1.md). Preserve all five columns and the 13 original rows in order: Bone, Cartilage, Capsule, Ligament, Tendon, Muscle, Fascia, Nerve, Vessel, Bursa, Fat, Skin, Viscus. Append case-relevant additional classes when needed, without deleting/reordering base rows or forcing Joint/Disc into an unreliable mapping.
2. Record supporting and opposing findings with source locators; use Not provided for missing findings. Fill the support column with one approved status and its case rationale. Unexamined categories may remain unknown; do not populate all rows with plausible diagnoses. Major unresolved supporting/opposing conflict uses ⚠ Conflicting evidence.

### Phase 2: System and Regional Evidence Analysis

Read [Table 3.2](assets/table-3-2.md). Use FIVE distinct columns, including separate Upstream and Downstream and Regions. Keep the six base system rows; append relevant other categories when needed. Use the exact corrected Regions title and an approved involvement status with reason.

### Phase 3: Hypothesis Update and Handoff

1. After the tables, include Clinical Contradiction Alerts / Insufficient Evidence, then the clinical-contract Red Flags, Yellow Flags and Reasoning Rationale and Limitations. Refer to table evidence without recopying it. State which preliminary hypotheses were supported, weakened or remain undecidable and what would distinguish them.
2. Stop before Table 4/full Impression and invite a clear forward request. If a complete combined analysis was explicitly requested, proceed using the available Impression skill as described in stage routing. Without that capability, state the limitation rather than improvising completion.

## Interpretation Checks

Do not mistake missing sensory/neurodynamic findings for negatives. Possible neural involvement and suspected neural mechanosensitivity are not automatically neuropathic pain. Breathing response, posture, a fascial pathway or isolated provocative finding does not establish a specific causal lesion. Check method/source and population applicability when recommending a test; uncertain methods remain uncertain. Source examples' ratings are not defaults.

When interpreting pain descriptors, consult the shared [pain-mechanism guide](../../references/pain-mechanisms.md).
